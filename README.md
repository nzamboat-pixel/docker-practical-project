
# Docker Practical Project

## Project Description
This project demonstrates Docker, Docker Compose,
Git and GitHub-based application deployment.

## Technologies
- Ubuntu Linux
- Docker
- Docker Compose
- Python Flask
- Redis
- Git
- GitHub

## How to Run

Start the application:

sudo docker compose up -d --build

Access the application:

http://SERVER_IP:8082

## Stop the Application

sudo docker compose down
